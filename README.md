# 智能家常菜谱小程序

基于 uni-app、Vue 3、TypeScript 和 Pinia 开发的家常菜谱小程序。

## 项目简介

用户可以录入家常菜做法，生成可编辑的菜谱内容，修改菜名、菜系、烹饪时间和制作步骤，确认后保存到菜谱列表。

后续计划支持组内点菜、菜谱制作记录、制作频率统计和 AI 菜谱规范化。

## 技术栈

- uni-app
- Vue 3
- TypeScript
- Pinia
- 微信小程序

## 当前功能

- 菜谱列表双列展示
- 添加菜谱页面
- 输入原始菜谱文本并生成初步内容
- 编辑菜名、菜系和烹饪时间
- 编辑、添加和删除制作步骤
- 选择菜谱封面图
- 保存菜谱并返回列表
- 使用 `mealCategory` 区分早餐、正餐、甜品、小吃和饮品
- 使用 `category` 保存菜系信息，例如川菜、粤菜
- 旧菜谱未设置 `mealCategory` 时，默认按“正餐”处理

### 点菜

- 从首页进入点菜菜单
- 按菜品分类筛选菜单
- 添加或取消菜品
- 查看已点菜品及当前点菜数量
- 提交点菜后，所选菜品的制作次数加一

### 路由

- 使用项目路由封装发起页面跳转
- 通过全局路由守卫统一执行导航前检查，例如登录状态验证、权限检查等
- 支持页面参数传递，例如从列表页跳转详情详情页时传递菜谱 ID

## 项目结构

```text
src/
  components/     # 页面复用组件
  composables/    # 计划存放可复用业务逻辑
  constants/      # 计划存放分类、默认值等常量
  pages/          # 页面
  repositories/   # 计划存放数据访问逻辑
  router/         # 路由封装和守卫
  stores/         # Pinia 状态管理
  types/          # TypeScript 类型
  utils/          # 计划存放校验、反馈等工具函数


> 当前生成菜谱使用前端本地规则模拟，尚未接入 AI 服务和后端。

## 本地运行

安装依赖：

\`\`\`bash
npm install
\`\`\`

运行微信小程序开发版本：

\`\`\`bash
npm run dev:mp-weixin
\`\`\`

编译后使用微信开发者工具打开：

\`\`\`text
dist/dev/mp-weixin
\`\`\`
