# 智能家常菜谱小程序

基于 uni-app、Vue 3、TypeScript 和 Pinia 开发的家常菜谱小程序。

## 项目简介

用户可以录入家常菜做法，生成可编辑的菜谱内容，修改菜名、菜系、烹饪时间和制作步骤，确认后保存到菜谱列表。

后续计划支持组内点菜、菜谱制作记录、制作频率统计和 AI 菜谱规范化。

## 技术栈

- uni-app
- Vue 3
- TypeScript
- Pinia
- 微信小程序

## 当前功能

- 菜谱列表双列展示
- 添加菜谱页面
- 输入原始菜谱文本并生成初步内容
- 编辑菜名、菜系和烹饪时间
- 编辑、添加和删除制作步骤
- 选择菜谱封面图
- 保存菜谱并返回列表

> 当前生成菜谱使用前端本地规则模拟，尚未接入 AI 服务和后端。

## 本地运行

安装依赖：

\`\`\`bash
npm install
\`\`\`

运行微信小程序开发版本：

\`\`\`bash
npm run dev:mp-weixin
\`\`\`

编译后使用微信开发者工具打开：

\`\`\`text
dist/dev/mp-weixin
\`\`\`
